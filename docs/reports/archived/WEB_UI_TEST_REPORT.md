1. 在 Chrome 中访问应用
2. 查看浏览器地址栏右侧
3. 点击"安装"或"添加到主屏幕"图标
4. 确认安装

#### 桌面浏览器
1. 在支持 PWA 的浏览器中访问应用
2. 查看地址栏或浏览器菜单
