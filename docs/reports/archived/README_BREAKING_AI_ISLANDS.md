```
用户界面 (Web Dashboard)
    ↓
智桥监控器 (Process Monitor)
    ↓
智桥工作流引擎 (Workflow Engine)
    ↓
智桥Agent注册表 (Agent Registry)
    ↓
智桥消息总线 (Message Bus)
```

1. **AIProcessMonitor** - 进程发现与监控
2. **AgentRegistry** - Agent注册与发现
3. **MessageBus** - 消息路由与通信
4. **WorkflowEngine** - 工作流编排与执行
5. **Dashboard** - 可视化监控界面
